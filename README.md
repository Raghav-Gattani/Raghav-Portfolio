# 📚 Straw Hat Reading List

A reading list app with a One Piece theme, built with HTML, CSS and JavaScript.

**🌐 Live app:** https://quiz-app-gc4c.vercel.app/

## How it works
1. Type a title (and author) and click **Add book**.
2. Mark a book as **Read** / **Unread** with one click.
3. Delete books with the 🗑 button.
4. Filter by **all / to read / read**; a counter shows your progress.
5. Data is saved in the browser's `localStorage`, so the list survives refreshes.
